# Ownership

All code in this repository is OneSmarter code.

- `agents_service/agents/cv/` and `agents_service/agents/linkedin/`, plus the file
  reading in `agents_service/documents/`, come from OneSmarterInc/Kormic-careers-backend
  (branch `production-ready`), which adapted them from OneSmarterInc/Kormic_backend_sahil_ammar
  and OneSmarterInc/Linkedin_agent. All three are OneSmarter repositories (confirmed by the
  repository owner, 19 Oct 2026).
- `agents_service/agents/nppes/`, `oig/` and `sam/` are ported from OneSmarter's
  `kormic-agents` package (shared by the repository owner on 19 Oct 2026).
- `legacy/` holds the October 2026 pilot of this repository, kept for reference.

Third-party libraries, Tesseract and the Qwen model keep their own licences.
